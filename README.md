# spgs-hackathon-submission

The Hammersmith Academy submission for the St Paul's Girls School Hackathon 2026 - Reduce, Reuse, Recycle.

## **THIS PROJECT REQUIRES AN OPENAI API KEY TO WORK**

To use this project, you must create a file in `src/` named `.env` and set two options there:

* `API_KEY` - Your OpenAI API Key.
* `MODEL` - The model you want to use. If you're on the free plan, which you most likely are, use `gpt-6-luna`
